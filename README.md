# GeoLens：遥感垂直域多模态助手

用"自动数据构建 + 置信度清洗 + LoRA 微调"把通用小型多模态模型适配到遥感影像理解域。

**状态**：🚧 开发中（Phase 0）。计划详见 [PLAN.md](./PLAN.md)。

## 它解决什么问题

通用视觉-语言模型对遥感俯拍影像存在严重域差距：地物识别错误、描述幻觉。GeoLens 用一套低成本数据流水线（CLIP 零样本打标 → 熵加权置信度过滤 → 指令数据生成）自动构建垂直域训练数据，并通过"清洗 vs 未清洗"对照实验量化数据质量对微调的贡献。
